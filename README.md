# Stackwell

Astro 5 static landing for a plumber covering Melbourne inner north and west. Template id `stackwell`. MIT. Light-custom: logo, colours, fonts, copy, section on/off. No CMS, auth, payments or ecommerce.

Live demo: https://stackwell.little.website/

- Brand tokens live in `src/styles/global.css` (paper, slate, terracotta, brass, mist).
- Contact form is a plain `mailto:sales@little.cloud` — no fake JS submit.
- Fonts: Barlow Condensed (display), Karla (body), IBM Plex Mono (eyebrows), loaded once in the document head.
- Hero: “Drips don't fix themselves.”

```sh
bun install
bun run dev
bun run build
```
